### 力传传感器通讯协议

#### 物理接口
传感器通信接口为CAN，使用CAN标准模式数据帧进行通讯，传感器只会对符合通讯ID的指令进行响应。

**通信参数**

| 通讯参数内容 | 通讯参数 | 备注 |
| :--- | :--- | :--- |
| 速率 | 默认1Mbps | |
| 通讯ID | 主机->传感器：0x521+Add<br>传感器->主机：0x521+Add | Add为传感器地址，默认为1。 |

#### 指令说明
数据帧中数据均为十六进制，涉及到U32、float等多字节数据时，数据格式为MSB。如U32型数据100在指令中表示为0x00 0x00 0x00 0x64，float型数据10.1在指令中表示为0x41 0x21 0x99 0x99。

---

#### 1.通用应答
通用应答为主机向传感器发送指令后，传感器向主机回传执行状态。  
传感器应答：

| 帧类型 | 帧ID | DLC | 数据 | |
| :--- | :--- | :--- | :--- | :--- |
| 数据帧 | 0x521+Add | 2 | 0x41 | 回传状态(U8) |

回传状态：

| 回传状态字段 | 说明 |
| :--- | :--- |
| 0x00 | 指令正确 |
| 0x01 | 无效命令 |
| 0x02 | 非法参数 |
| 0x03 | 存储失败 |

#### 4.设置分度值
上位机发送：

| 帧类型 | 帧ID | DLC | 数据 | | |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 数据帧 | 0x521+Add | 3 | 0x57 | 0x02 | 分度值(U8) |

分度值为传感器输出测量值分辨力，测量值以对应分度值进行跳变，分度值默认为1N（0x03）。分度值范围：

| 分度值字段 | 说明 |
| :--- | :--- |
| 0x00 | 分度值为0.1N |
| 0x01 | 分度值为0.2N |
| 0x02 | 分度值为0.5N |
| 0x03 | 分度值为1N |
| 0x04 | 分度值为2N |
| 0x05 | 分度值为5N |
| 0x06 | 分度值为10N |

传感器使用通用应答回复。

#### 10.设置自动发数间隔
上位机发送：

| 帧类型 | 帧ID | DLC | 数据 | | |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 数据帧 | 0x521+Add | 4 | 0x57 | 0x07 | 发数间隔(U16) |

当上位机连续获取测量值时，传感器将按照自动发数间隔不停回传测量数据，自动发数间隔范围1ms-2000ms，默认1ms(设定值为10，即设定值为设定时间的10倍为了以后可以提高通讯速率)。传感器使用通用应答回复。

#### 12.查询版本号
上位机发送：

| 帧类型 | 帧ID | DLC | 数据 | |
| :--- | :--- | :--- | :--- | :--- |
| 数据帧 | 0x521+Add | 2 | 0x51 | 0x09 |

传感器回复。

| 帧类型 | 帧ID | DLC | 数据 | | | | |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 数据帧 | 0x521+Add | 7 | 0x51 | 0x09 | 预留(U8) | 版本号(U8) | 日期(U8+U8+U8) |

日期为3字节，表示软件最新一次修订时间，高字节为年，中间字节为月，低字节为日。  
如0x01 0x01 0x18 0x07 0x1E，表示F400型，版本01，日期24/07/30。

#### 13.获取AD码值
上位机发送：

| 帧类型 | 帧ID | DLC | 数据 | | |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 数据帧 | 0x521+Add | 3 | 0x44 | 0x01 | 取数模式(U8) |

取数模式：

| 取数模式字段 | 说明 |
| :--- | :--- |
| 0x00 | 停止取数，传感器停止回复 |
| 0x01-0xFE | 固定次数取数，传感器回复对应次数 |
| 0xFF | 连续取数，传感器按照自动发数间隔不停回复 |

传感器回复：

| 帧类型 | 帧ID | DLC | 数据 | | |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 数据帧 | 0x521+Add | 6 | 0x44 | 0x01 | AD码值(int) |
