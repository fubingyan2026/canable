# 补光灯控制插件

依据 `claw_ctrl/docs/can-protocol.md` V1.1（2026-11-10），用于夹爪控制板的补光灯调光和心跳监控。

1. 在上位机主界面选择 **CAN FD、仲裁速率 1 Mbps** 后连接适配器。
2. 在“插件”菜单打开“补光灯控制”。
3. 通过滑条或百分比输入设置亮度，点击“应用亮度 / 重发”。支持 0.1% 步进。
4. “开灯”恢复最后一次非零设置，“关灯”立即发送 0%；25%、50%、75%、100% 预设点击即发送。
5. 可勾选“调整后自动发送”，停止调整 150 ms 后发送最后一个值，避免拖动时大量发帧。

插件固定发送标准数据帧 `0x220`，**FD=1、BRS=0、DLC=8**。
数据为 `01 01 LL HH 00 00 00 00`，PWM 值 0～1000，小端编码，50% 对应 500：
`01 01 F4 01 00 00 00 00`。没有节点地址设置，协议面向总线上的一块控制板。

状态帧 `0x221` 每 500 ms 上报；插件用本地单调时钟判断在线，1500 ms 未收到合法帧即标记失联。
首次收到心跳前显示“未确认在线”。显示板端目标亮度、电机汇总状态和 MCU 运行时间；失联时清除过期显示。

发送命令后，插件等待新的状态快照，核对板端目标值。1500 ms 内未匹配显示超时，可点击应用重发。
这是状态核对，不是带序号的事务 ACK，也不能证明灯珠实际亮度。
协议没有实际 PWM/光学亮度测量；非零目标在控制板端平滑变化，约 0.3 秒接近目标变化量的 95%，关灯绕过滤波。

断开连接、关闭插件或退出软件不发送关灯命令，板端按协议保持最后设置。
重连或重新打开插件不会自动下发记忆亮度；需要关灯时，请在断开前点击“关灯”并核对板端目标为 0%。

插件设置保存在 `plugin.fill_light.*` 命名空间，支持中文/英文界面。

离线验证：`python -B -m unittest discover -s tests -p test_fill_light.py -v`。
