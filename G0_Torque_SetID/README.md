# G0 力矩传感器扫描与标ID

仅使用标准CAN帧。请求CAN ID=`0x500 + 站号×0x10`，响应=`0x400 + 站号×0x10`。
按现有映射，标准帧可扫描/设置站号 **1～47（0x01～0x2F）**；站号48请求为0x800，超过0x7FF，因此不支持扫描到0xFF，不截断地址、不发送扩展帧。

## 使用

只连接一只待配置传感器，断开另一只的CAN连接并保持正确终端电阻，停止DHW及其它测试程序。主机须已配置SPI1 CS0。

推荐直接用脚本，新ID作为参数（自动编译、扫描并改号，不再交互确认）：

```bash
cd G0_Torque_SetID
sudo ./set_id.sh 2
# 十六进制也可以
sudo ./set_id.sh 0x02
```

脚本依赖CMake、C编译器、make、flock和pgrep；不自动安装系统包。参数必须在1～47范围内。
扫描异常仍拒绝改号。脚本会拒绝已运行的常见DHW/测试/标ID程序，但不能替代人工排除其它CAN占用者。

以下是不传参数时保留的交互方式：

```bash
cd G0_Torque_SetID
cmake -S . -B build
cmake --build build -j2
sudo ./build/g0_torque_set_id
```

1. 输入 `yes` 确认单只连接。
2. 程序依次查询1～47，每个ID等待50ms，总计约3秒。
3. 显示当前ID后输入目标ID（十进制如 `2`，或十六进制如 `0x02`），范围同为1～47。
4. 再输入 `yes` 才发送改号，成功打印 `设置ID=2 OK`。

也可直接执行已编译程序 `sudo ./build/g0_torque_set_id 2`，参数模式跳过两次确认。

SPI `/dev/spidev1.0`、5MHz、晶振40MHz、CAN 1Mbps；不依赖DDS或spdlog。

## 帧格式与安全限制

- 查询：DLC=8，`04 00 00 00 00 00 00 00`，按本次要求使用8字节。
- 识别：仅接受标准帧、对应响应ID、DLC 7或8、`04 00 00`开头及有限的大端float32数值。旧版4字节主动上报不作为查询应答。
- 改号：向扫描得到的当前地址发送DLC=7，`10 00 90`加目标站号的大端float32。例如目标2为 `10 00 90 40 00 00 00`。
- 成功应答：旧地址或新地址返回 `10 00 90 3F 80 00 00`，等待最多1秒。
- 扫描无响应、多个ID响应或某次查询收到多个匹配应答时拒绝改号。主动上报也可能导致多回复，需先停止主动上报；本工具不会自动发送停报命令。
- **扫描只发现一个ID、一帧回复也无法排除同ID设备重叠回复，必须物理确保只接一只。** 回复条数不是设备数。
- 查询及改号不进行应用层重发，控制器限制重发并在查询窗口后中止待发送帧。超时可能已改号，不要盲目重发；重新查询确认。
- OK表示收到写成功应答，不代表已验证掉电保存。协议未提供保存/重启要求，不额外发送此类命令。

返回0成功、1通信/扫描失败、2输入错误或取消。本版编译及离线协议测试通过，未执行实际改号；地址高段、8字节查询和目标站号实际支持范围仍需传感器实机确认。
