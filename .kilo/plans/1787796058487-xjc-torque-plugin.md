# 鑫精诚扭矩传感器（CAN V1.2）上位机插件实施计划

- 目标插件：`plugins/xjc_torque`，中心 Tab 名「鑫精诚传感器」/ XJC Sensor
- 协议依据：`docs/鑫精诚扭矩传感器CAN协议帧V1.2.md`，以**正文 1~19 节**为准；目录里的重力加速度两节正文缺失，本版不做
- 本计划只描述实现方案；修改源码请切换到可执行实现的 agent

---

## 1. 目标

1. **能读**：连续采集 `44 02 FF` 实时显示测量值；支持单次读取与 AD 码值读取
2. **能清 0**：主按钮发 `5A 01`（当前值置零并保存）；维护区另有 `43 01` 零点标定、`5A 02` 置零不保存、上位机软件零点
3. **波形**：单通道实时曲线，时间窗 1/2/5/10/20 s，暂停/继续/清除，尖峰不丢失
4. **保存**：勾选记录后把采样写入 CSV，可一键打开文件
5. **查询版本号** `51 09`，**重启传感器** `52 42`
6. **界面简洁专业**：栅格对齐、单位独立固定显示、大号数值、可滚动、中英双语
7. **稳定**：命令超时可控、断开与关闭必停流、忽略 TX 回显、离线判定、异常不崩溃

## 2. 已确认决策

| 项 | 决策 |
| :--- | :--- |
| 主清 0 指令 | `5A 01` 置零并保存，需二次确认 |
| 其它归零 | 维护区提供 `43 01` 零点标定、`5A 02` 置零不保存、软件零点（只改显示并持久化） |
| 满程标定 `43 02` | v1 不做 UI，protocol.py 保留构造器 |
| 默认发数间隔 | 10 ms（值 100）；出厂 1 ms（值 10），面板可设 1~2000 ms |
| 波形控件 | 复制 `plugins/torque_sensor/scope.py` 并精简为单通道，保持插件自包含 |
| 保存格式 | CSV，列 `iso_time, t_s, raw, zeroed`，写在 exe 所在目录 |
| 地址 | 单地址 1~31（默认 1），ID = `0x521 + Add` |
| AD 码值 | 仅按钮单次读取，不参与连续流 |

## 3. 协议摘要（全部大端 MSB）

CAN 2.0 标准数据帧，1 Mbps；请求与响应 **ID 相同** = `0x521 + Add`（默认 1 → `0x522`）；无应用层校验。

### 3.1 主机到传感器

| 操作 | 数据（DLC） | 说明 |
| :--- | :--- | :--- |
| 开始连续取力值 | `44 02 FF`（3） | 按发数间隔不停回传 |
| 单次取力值 | `44 02 01`（3） | 回 1 帧 |
| 停止取数 | `44 02 00`（3） | 离开面板/断开必须发 |
| 取 AD 码值 | `44 01 01`（3） | 单次 |
| 零点标定 | `43 01`（2） | 通用应答 |
| 开机置零（保存） | `5A 01`（2） | 主清 0 |
| 按键置零（不保存） | `5A 02`（2） | 通用应答 |
| 满程标定 | `43 02` + U32（6） | v1 仅保留构造器 |
| 设置地址 | `57 01` + newAddr（3） | 通用应答 |
| 查询地址 | `51 01`（2） | |
| 设置分度值 | `57 02` + U8（3） | 0x00..0x06 → 0.1/0.2/0.5/1/2/5/10 N |
| 查询分度值 | `51 02`（2） | |
| 设置滤波等级 | `57 03` + U8（3） | 0..5，0 不滤波 |
| 查询滤波等级 | `51 03`（2） | |
| 设置 AD 参数 | `57 06` + U16 采样率 + U8 增益（5） | 2400/1200/600/300/150/75，128/64/32/16/1；高级，需确认 |
| 查询 AD 参数 | `51 06`（2） | |
| 设置发数间隔 | `57 07` + U16（4） | 值 = 毫秒 × 10 |
| 查询发数间隔 | `51 07`（2） | |
| 查询版本号 | `51 09`（2） | |
| 重启传感器 | `52 42`（2） | 无应答 |

### 3.2 传感器到主机

| 回包 | 数据（DLC） | 解析 |
| :--- | :--- | :--- |
| 通用应答 | `41 xx`（2） | 00 OK；01 无效命令；02 非法参数；03 存储失败 |
| 力值 | `44 02` + float32（6） | 非有限值判无效帧 |
| AD 码值 | `44 01` + int32（6） | 有符号 32 位 |
| 地址 | `51 01` + U8（3） | |
| 分度值 | `51 02` + U8（3） | |
| 滤波 | `51 03` + U8（3） | |
| AD 参数 | `51 06` + U16 + U8（5） | |
| 发数间隔 | `51 07` + U16（4） | 值 ÷ 10 = ms |
| 版本 | `51 09` + 类型 + 版本 + 年月日（7） | 例 `01 01 18 07 1E` = 类型 0x01(F400)，版本 01，日期 2024-07-30 |

RX 分派按 `data[0]`：0x41 应答，0x44 数据，0x51 查询回包；**必须跳过 `frame.is_tx`**（自发帧会以回显形式回到插件）。

## 4. 文件与职责

| 文件 | 职责 |
| :--- | :--- |
| `__init__.py` | 版本号 |
| `protocol.py` | 无 Qt：ID 计算、命令构造、回包解析、数据类、`__main__` 自测 |

| `widget.py` | 面板 UI、采集状态机、归零/参数/版本/重启、CSV 记录 |
| `plugin.py` | Plugin 子类，注册 i18n、转发生命周期、`create_plugin()` |

## 5. UI 规格

`QScrollArea` 包裹；栅格对齐；单位用独立固定宽度标签（不放进输入框 suffix）；数值绿色 `style.LOAD_LOW`，告警红 `style.LOAD_HIGH`；输入框滚轮步进统一由 `_WheelSpin` mixin 处理（参考 `plugins/juxie_motor/widget.py`）。

分组（自上而下）：

1. **传感器配置**：地址 1~31；在线状态 + 更新时间；发数间隔 + ms；开始采集 / 停止 / 单次读取 / 读取信息；连接后自动开始采集
2. **实时值**：大号数值（软件零点已应用）；原始值、软件零点、AD 码值；分度值、滤波等级、版本号、日期
3. **波形**：时间窗下拉、暂停/继续、清除、当前值；单通道曲线
4. **记录**：记录到 CSV 勾选、文件名 + 行数、打开按钮
5. **参数**：分度值 / 滤波 / 发数间隔 各自查询与设置；高级区 AD 采样率 + 增益（改前确认）
6. **标定与维护**：清 0（置零并保存）、零点标定、置零（不保存）、软件零点、清除软件零点、查询版本号、重启传感器
7. **原始报文**：TX/RX HEX 日志（最多 80 行自动清理）+ 清空

i18n 前缀统一 `Xjc.`，约 60 个 key（中英），单位 key 单独定义。

## 6. 采集状态机与稳定性

状态：idle / pending（等待通用应答）/ streaming。

- **开始采集**：先下发 `57 07`（间隔），收到应答或 300 ms 超时后发 `44 02 FF`；进入 streaming
- **停止采集**：发 `44 02 00`，回到 idle
- **单次读取**：`44 02 01`；**读取信息**：`51 09`、`51 07`、`51 01` 用 QTimer 串联，间隔 ≥ 100 ms
- **应答匹配**：同一时刻只允许一个 pending；收到 `41 xx` 按状态码提示；超时 300 ms 提示应答超时并复位；等待期间禁用其它需应答按钮
- **流与应答可交织**：按首字节分派，数据帧不干扰 pending 判定
- **离线判定**：streaming 下超过 max(1 s, 5×间隔) 无数据 → 状态转离线，不清除最后数值
- **无效数据**：float 非有限或 DLC 不等于 6 → 计入无效帧，仅在原始报文里标记
- **离开面板 / 断开 / 退出**：若仍 streaming 且已连接，必须发 `44 02 00`；在 `on_deactivating`、`on_disconnect`、`confirm_close` 中处理
- **未连接 / 非 Classic CAN**：未连接时按钮置灰并提示；`is_fd_mode()` 为真或 `get_bitrate() != 1000000` 时在连接时状态栏提示使用 1 Mbps
- **重启**：`52 42` 无应答 → 停止采集并提示；若此前 streaming 且勾选自动开始，2 s 后自动重发 `44 02 FF`
- **改地址**：`57 01 new` 需二次确认（提示要同时改面板地址）；收到 OK 后更新并持久化地址

## 7. CSV 记录

- 文件名：`xjc_<addr>_YYYYmmdd_HHMMSS.csv`，目录取 exe 目录（`sys.frozen`）否则工程根目录
- 表头：`iso_time,t_s,raw,zeroed`；每条采样一行；`t_s` 为距开始记录秒数（3 位小数）
- 缓冲写入，每 100 行或停止记录时 flush；停止/关闭面板/退出时关闭文件
- 面板显示文件名与行数；打开按钮用 `QDesktopServices.openUrl`
- 未勾选时不创建文件；记录中关闭 Tab 时 `confirm_close()` 弹确认

## 9. 验证

### 9.1 协议自测 `python -m plugins.xjc_torque.protocol`

- 每条命令字节与 §3.1 完全一致（含 `57 07 00 64` = 10 ms、`44 02 FF`、`52 42`）
- 解析：`41 00/01/02/03`、`44 02 3F800000 → 1.0`、`44 01 FF FF FF 9C → -100`、`51 09 01 01 18 07 1E → 类型 0x01 / 版本 1 / 2024-07-30`、`51 07 00 64 → 10 ms`
- 换算双向一致（ms 与 raw、分度值 code 与 N）

### 9.2 offscreen 集成测试（假 ctx，参考现有 test_battery.py 写法）

1. 开始采集发 `44 02 FF`（ID `0x522`），停止发 `44 02 00`
2. 回灌连续力值帧（含 1 帧 NaN、1 帧 DLC 错误）→ 大号值更新、波形桶数大于 0、无效帧计数 +2
3. TX 回显（is_tx=True）被忽略
4. 清 0 → 确认 → 发 `5A 01`；回 `41 00` 提示成功；回 `41 02` 提示非法参数；无应答 300 ms 后提示超时
5. 查询版本 → 发 `51 09`；回版本帧后显示版本 / 日期 / 类型码
6. 重启 → 发 `52 42`，不报超时，采集状态停止
7. 改地址 1→5 → 发 `57 01 05`；回 OK 后地址持久化，后续命令 ID 变 `0x526`
8. 记录 → 写入若干行，表头与行数正确，停止后文件可读；未勾选时不建文件
9. 生命周期：streaming 时 on_disconnect / on_deactivating 发 `44 02 00` 并停定时器；refresh_language 不抛异常；暂停时波形冻结

### 9.3 硬件手测

1 Mbps Classic CAN、地址 1；数值随加载变化、波形连续；清 0 后归零且断电重连仍为零（验证保存语义）；重启后自动恢复采集；版本日期与实物一致。

## 10. 风险与不做项

- 文档目录与正文不一致：重力加速度相关章节正文缺失，v1 不实现也不猜字节
- 满程标定会写入标定数据，v1 不提供 UI
- 请求与响应同 ID，必须靠 is_tx 区分回显
- 连续流默认 10 ms；设为 1 ms 时跟踪表会非常繁忙，离开面板会自动停流
- 改地址后需记住新地址，确认框必须提示
- 协议无应用层校验，依赖 CAN 控制器错误帧判断，插件只展示不重试风暴
